# Email Design System

Reusable MJML components and templates used to build Joe Browns CRM emails.

## Purpose

This repository exists to:

- Store reusable MJML components.
- Keep email templates organised.
- Track changes using Git.
- Document coding standards and best practices.
- Make collaboration between Design and CRM Development easier.

---

## Project Structure

/components
Reusable components (Header, Footer, Navigation, Buttons, Panels)

/templates
Complete email templates and layouts.

/docs
Coding standards, documentation and guides.

/assets
Reference images and supporting assets.

---

## Workflow

1. Create or update a component.
2. Test in MJML.
3. Test in Bloomreach.
4. Commit changes with a clear description.
5. Merge into the main branch when approved.

---

## Naming Conventions

- Use PascalCase for component filenames.
- Keep components modular and reusable.
- Avoid duplicate components where possible.

Examples:

Header.mjml
Footer.mjml
Navigation.mjml
VoucherPanel.mjml
SocialPanel.mjml
