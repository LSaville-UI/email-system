# Creating a New Reusable Component

## 1. Identify a repeatable pattern

The component should solve a problem that appears in multiple emails.

Avoid creating components for one-off campaigns.

---

## 2. Design

Create or update the design in Figma.

Check:

- Mobile
- Desktop
- Dark mode

---

## 3. Build

Develop the component in MJML.

Requirements:

- Responsive
- Accessible
- Reusable
- Minimal code

---

## 4. Test

- MJML Preview
- Bloomreach
- Gmail
- Outlook
- Apple Mail

---

## 5. Review

Questions:

- Can this replace an existing component?
- Is it configurable?
- Is the naming correct?

---

## 6. Commit

Commit with a clear message.

Example:

Add reusable navigation component

---

## 7. Documentation

Update:

- Component list
- Usage notes
- Screenshots (if required)
